## Proyecto Final DAW
<p>Este es el proyecto de final del ciclo formativo de Desarrollo de Aplicaciones Web</p>

## Sistema de Citas Online
<p>Esta aplicación web consta de un sistema de citas para una empresa de depilación láser en explotación compartida, donde diferentes tipos de usuarios podrán gestionar toda la información relevante de sus tratamientos.</p>
